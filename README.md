# Trading AI: ລະບົບເທຣດອັດຕະໂນມັດ + AI ສຳລັບ Prop Firm

ລະບົບເທຣດອັດຕະໂນມັດ (MT5 EA) ທີ່ມີ AI ຊ່ວຍວິເຄາະຂ່າວ, ບັນທຶກ ແລະ ຮຽນຮູ້ຈາກທຸກໄມ້,
ແລະ ສະເໜີການປັບປຸງ. ເປົ້າໝາຍແມ່ນເສັງຜ່ານ FTMO ແລ້ວສະເກວ.

**ສະຖານະ:** ໄລຍະ 1 (ດຶງຂໍ້ມູນ MT5 + trade journal) ແລະ ໄລຍະ 2 (backtest + ຈຳລອງການເສັງ FTMO) ມີໂຄດແລ້ວ. ໄລຍະ 3: RiskGuard EA (ໂຕຄຸມຄວາມສ່ຽງ) ກຳລັງພັດທະນາ. ວິທີໃຊ້ເບິ່ງ [docs/SETUP.md](docs/SETUP.md)
