# ແຜນໂປຣເຈັກ: ລະບົບເທຣດອັດຕະໂນມັດ + AI ສຳລັບເສັງ Prop Firm (FTMO)

> ເອກະສານແມ່ບົດ. ທຸກການຕັດສິນໃຈສຳຄັນຕ້ອງອັບເດດບ່ອນນີ້.
> ບໍ່ແມ່ນຄຳແນະນຳດ້ານການເງິນ. ຜົນໃນອະດີດບໍ່ຮັບປະກັນອະນາຄົດ.

## 1. ເປົ້າໝາຍ

ສ້າງລະບົບເທຣດອັດຕະໂນມັດ 100% ທີ່:

1. ມີ **edge ທີ່ພິສູດໄດ້** ດ້ວຍຂໍ້ມູນ, ບໍ່ແມ່ນຄວາມຮູ້ສຶກ
2. **ບໍ່ເຄີຍລະເມີດກົດຂອງ prop firm** (ມີ Risk Manager ເປັນກົດເຫຼັກ)
3. **ບັນທຶກ ແລະ ຮຽນຮູ້ຈາກທຸກໄມ້**: ເປັນຫຍັງໄດ້, ເປັນຫຍັງເສຍ
4. ໃຊ້ **AI ຮອບດ້ານ**: ວິເຄາະຂ່າວ, ຊອກຕົ້ນເຫດ, ສະເໜີການປັບປຸງ, ລາຍງານ
5. ຜ່ານການເສັງ FTMO → ຖອນເງິນໄດ້ສະໝ່ຳສະເໝີ → ສະເກວຫຼາຍບັນຊີ, ຫຼາຍແພລດຟອມ

## 3. ກົດເຫຼັກ (ຫ້າມລະເມີດ)

1. **ຫ້າມປິດບອດ ຫຼື ແກ້ຄ່າ ເພາະຄວາມຮູ້ສຶກ.** ປ່ຽນໄດ້ສະເພາະເມື່ອມີຂໍ້ມູນ ແລະ ຜ່ານ backtest ແລ້ວ.
2. **AI ເບກໄດ້ສະເໝີ, ແຕ່ເລັ່ງຄວາມສ່ຽງເອງບໍ່ໄດ້.** AI ຍົກເລີກ Risk Manager ບໍ່ໄດ້.
3. **ເສຍໃນມື້ດຽວເຖິງ 3% → ປິດທຸກອໍເດີ ແລະ ຢຸດເທຣດຮອດມື້ໃໝ່** (ກັນໄວ້ກ່ອນເສັ້ນ 5% ຂອງ FTMO).
4. **ເກນຢຸດກົນລະຍຸດ:** ຖ້າ drawdown ຈິງ > drawdown ທີ່ແຮງທີ່ສຸດໃນ backtest × 1.5 → ຢຸດ ແລະ ທົບທວນ.
5. **ຫ້າມ hedge ຂ້າມບັນຊີ ຫຼື ຂ້າມບໍລິສັດ, ຫ້າມ HFT ຫຼື latency arbitrage.** ຜິດກົດ prop firm.
6. **ບໍ່ປັບກົນລະຍຸດຈາກຂໍ້ມູນໜ້ອຍ.** ຕ້ອງມີຢ່າງໜ້ອຍ 30–50 ໄມ້ຕໍ່ເງື່ອນໄຂ ແລະ ຜ່ານ walk-forward.
7. **ບໍ່ຈ່າຍຄ່າເສັງ ຖ້າຕົວຈຳລອງການເສັງບອກວ່າໂອກາດຜ່ານຕ່ຳ.**
8. **ຢ່າໃສ່ API key ຫຼື ລະຫັດຜ່ານໃນ repo.** ໃຊ້ໄຟລ໌ `.env` ເທົ່ານັ້ນ.
9. **ກວດກົດລ່າສຸດຂອງ prop firm ທຸກເທື່ອກ່ອນເສັງ.** ກົດປ່ຽນໄດ້ເລື້ອຍໆ.

## 4. ລະດັບອຳນາດຂອງ AI

| ລະດັບ | AI ເຮັດຫຍັງໄດ້ | ເງື່ອນໄຂຂຶ້ນລະດັບຕໍ່ໄປ |
|---|---|---|
| **0: ຜູ້ສັງເກດ** (shadow) | ໃຫ້ຄວາມເຫັນທຸກໄມ້ ແລະ ບັນທຶກໄວ້, ບອດບໍ່ເຮັດຕາມ | 100+ ໄມ້ ແລະ ພິສູດວ່າເຮັດຕາມ AI ຈະດີກວ່າ |
| **1: ເບກ** | ຫຼຸດ lot (0–100%) ຫຼື ຢຸດເທຣດຊົ່ວຄາວ | ພິສູດວ່າການເບກຫຼຸດ drawdown ໄດ້ແທ້ |
| **2: ຕົວກອງ** | ປະຕິເສດສັນຍານທີ່ປະເມີນວ່າໂອກາດຕ່ຳ | ພິສູດກັບຂໍ້ມູນຈິງ (out-of-sample) |

## 7. ຕົວຊີ້ວັດທີ່ຕ້ອງຕິດຕາມ

- **ກົນລະຍຸດ:** Profit factor, win rate, expectancy (R), max drawdown, Sharpe, ຈຳນວນໄມ້
- **ການເສັງ:** ໂອກາດຜ່ານ (%), ຈຳນວນມື້ສະເລ່ຍກ່ອນຜ່ານ, ໂອກາດຕີເສັ້ນຂາດທຶນຕໍ່ມື້ ຫຼື ເສັ້ນລວມ
- **AI:** ຜົນຂອງ shadow mode ທຽບກັບບອດ (ຖ້າເຮັດຕາມ AI ຈະດີກວ່າ ຫຼື ບໍ່)
- **ຄວາມສອດຄ່ອງ:** ຜົນຈິງທຽບກັບ backtest (slippage, spread, ຄວາມຖີ່ການເທຣດ)
